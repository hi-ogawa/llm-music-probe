# Agent Guide

See [README.md](README.md) for what is where.

- Start each experiment from [experiments/TEMPLATE.md](experiments/TEMPLATE.md) as `experiments/<nn>-<slug>/README.md`.
- Record the musical iteration: the listener's requests verbatim and the musical change that answered each. Keep tooling details out of that record, and put context in Setup.
- Record the exact model ID.
- Keep the agent's raw output, such as scripts and the saved project, in the experiment directory.
- Commit after each meaningful change, with Conventional Commits messages.
