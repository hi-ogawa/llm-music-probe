# Next

Sessions to run next, each aimed at one idea from the [reading](README.md#how-to-steer-it) that no session has tested yet. The composing agent gets only the prompts, as [experiments/README.md](../experiments/README.md) says.

- **Elements against sketches.** The same late-night neo-soul piece prompted two ways: references plus three 4-bar sketches to pick from, and a single prompt that spells out form, energy per section, roles, groove placement, harmonic rhythm, and variation. Both are running as of 2026-10-12.
- **References, bare and unpacked.** A prompt that names a record for the drums, against the same prompt with the reference written out as techniques. Asking the model first what the reference means shows what it reads into it.
- **More parts.** The same prompt with a small band and with a large palette that enters and leaves by section, to hear whether the extra room turns into variation.
- **Melody on its own.** A fixed chord loop and groove, with only the melody to write, in two or three versions under different constraints.
- **Feedback about the sound.** Mid-session feedback such as "sounds thin" or "it doesn't breathe", without naming the fix, to see which ones land.

The directions from the earlier question, such as depth, notation robustness, and fast decision models, are in [history.md](history.md#directions-retired-2026-10-12).
