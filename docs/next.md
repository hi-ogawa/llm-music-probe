# Next

Sessions to run next, each aimed at one idea from the [README](../README.md#how-to-steer-it) that no session has tested yet. The composing agent gets only the brief, as [experiments/README.md](../experiments/README.md) says.

- **Elements against sketches.** The same late-night neo-soul brief run two ways: references plus three 4-bar sketches to pick from, and a one-shot brief that spells out form, energy per section, roles, groove placement, harmonic rhythm, and variation. Both are running as of 2026-10-12.
- **References, bare and unpacked.** A brief that names a record for the drums, against the same brief with the reference written out as techniques. Asking the model first what the reference means shows what it reads into it.
- **More parts.** The same brief with a small band and with a large palette that enters and leaves by section, to hear whether the extra room turns into variation.
- **Melody on its own.** A fixed chord loop and groove, with only the melody to write, in two or three versions under different constraints.
- **A note about the sound.** Mid-session notes such as "sounds thin" or "it doesn't breathe", without naming the fix, to see which ones land.
